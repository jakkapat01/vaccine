# ตั้งช่วงค่าปกติของเซนเซอร์บน OLED

Admin PIN → ADMIN SETTINGS → เลื่อน D4/D5 ไป TEMP RANGE หรือ LIGHT RANGE → D2

1. ตั้ง MIN ด้วย D4 ลด / D5 เพิ่มครั้งละ 1 หน่วย → D2 NEXT
2. ตั้ง MAX ด้วย D4/D5 → D2 SAVE
3. บันทึกได้เมื่อ MIN < MAX เท่านั้น หากไม่ผ่าน แก้ MAX หรือ D3 กลับไปแก้ MIN
4. D3 จากหน้า MIN ยกเลิกกลับ Settings โดยไม่เปลี่ยนค่าที่ใช้อยู่

TEMP RANGE: -40 ถึง 125°C ค่าเริ่มต้น 2–8°C
LIGHT RANGE: 0 ถึง 100% ค่าเริ่มต้น 0–100% เป็นเปอร์เซ็นต์จาก ADC ไม่ใช่ lux

ค่าทั้งคู่ในแต่ละช่วงบันทึกพร้อมกันหลัง SAVE เท่านั้น ผู้ใช้ Nurse ตั้งค่าไม่ได้ CONFIG ผ่าน Console ของ Admin แสดงช่วงปัจจุบันได้

## ผลต่อระบบ

- ช่วงอุณหภูมิใช้กับ ADC Analog Watchdog และระยะอุณหภูมินอกเกณฑ์ในสูตร Risk/Health ร่วมกัน มีผลหลังบันทึก ไม่ย้อนคืน Health ที่เสียไปแล้ว
- Watchdog ปรับ threshold raw ตามสูตร NTC เดิม และเริ่มเทียบช่วงใหม่ในการอ่านเซนเซอร์รอบถัดไป ไม่มีการเปลี่ยน calibration ของเซนเซอร์
- ช่วงแสงใช้แจ้ง LIGHT ALARM จาก main loop เมื่ออ่านค่าทุก 500 ms ไม่ใช่ Interrupt แสงใหม่ สูตรผลของแสงต่อ Health ระหว่างเปิดฝายังเดิม
- กด D3 รับทราบแล้วกลับหน้าที่ค้างไว้ การรับทราบไม่เปลี่ยนค่าปกติที่ตั้งไว้
- มี hysteresis ตอนกลับมารอเตือนใหม่: อุณหภูมิเว้นจากขอบไม่เกิน 1°C (ลดตามความกว้างช่วง), แสงไม่เกิน 2 จุดเปอร์เซ็นต์
- LED 4 ดวงยังใช้เตือนเปิดฝาเกินเวลา ไม่ได้เปลี่ยนให้กระพริบเมื่อแสงผิดช่วง
- ไม่สั่ง Servo เปิด/ปิดเองจากการตั้งค่าช่วง

ค่าตั้งทั้งหมดอยู่ RAM รีเซ็ตกลับค่าเริ่มต้น เป็นเกณฑ์แบบจำลองในชั้นเรียน ไม่ใช่ข้อกำหนดเก็บวัคซีนทุกชนิด

ตัวอย่างสาธิต: TEMP RANGE 20–35°C สำหรับห้องประมาณ 27°C จะไม่แจ้ง TEMP ALARM แต่คะแนนเดิมไม่ฟื้น; LIGHT RANGE 20–80% แล้วทดลองบังหรือส่องแสงให้ค่าออกนอกช่วง
