# เปลี่ยนการเลือกเป็น D4 / D5

- D4 (PB5): ซ้าย/ลดค่า
- D5 (PB4): ขวา/เพิ่มค่า
- D2 (PA10): ยืนยัน
- D3 (PB3): ลบเลข/ย้อนกลับ/ออกจากระบบตามหน้า

หน้า PIN แสดงเลขที่กำลังเลือกตัวใหญ่ระหว่างลูกศร กด D4/D5 เลือกเลข 0–9 แล้ว D2 บันทึก เลขที่บันทึกถูกปิดด้วย * กด D3 ลบเลขที่บันทึกล่าสุด

หน้าเลือกโหมด/ขวด/ผลการนำขวดออก ใช้ D4/D5 เลื่อนตัวเลือกแล้ว D2 ยืนยัน ตัวเลือกวนหัวท้ายได้ กดค้างไม่เลื่อนซ้ำอัตโนมัติ และการกดพร้อมกันไม่ยืนยันรายการ

เข้าเมนูใหม่เริ่มที่ตัวเลือกแรก ยกเว้นหน้าขวดกลับไปยังขวดที่เลือกไว้; หน้าผลเริ่ม NO VIAL CHANGE เพื่อไม่เลือกจ่าย/เติมขวดโดยอัตโนมัติ

Pot ไม่ถูกอ่านโดยแอปแล้ว และไม่มีผลต่อเลข/เมนู การอ่านอุณหภูมิและแสงยังทำงานเหมือนเดิม PIN ผู้จ่าย 1234 และผู้ดูแล 2468

ใช้ F5 -> Clean/Build -> ลงโปรแกรมใหม่ ปิดฝาด้วยมือแล้ว D2 เพื่อเข้าหน้า PIN

ตรวจ Build ด้วย CubeIDE ในสำเนาแยก ไม่มี errors/warnings แต่ยังไม่ได้ทดสอบปุ่มจริงบนบอร์ด ตัวจำลอง ARM ที่เคยใช้มีปัญหาสิทธิ์เข้าถึงในรอบนี้ จึงไม่ได้อ้างว่ารันชุดทดสอบ behavioral รอบใหม่ผ่าน
