# OLED แบบกระชับและแถบ Health

ส่วนติดต่อผู้ใช้แบบกระชับ ใช้ D4/D5 เลือกเมนูและเลขแทน Pot

## ปุ่ม

- D4 (PB5): ซ้าย/ลดค่า วนหัวท้าย
- D5 (PB4): ขวา/เพิ่มค่า วนหัวท้าย
- D2: ยืนยัน
- D3: ลบ/ย้อนกลับ/ออกจากระบบตามหน้า

บรรทัดล่าง `4< 5> 2OK 3BACK` หมายถึงปุ่ม D4, D5, D2, D3 กดทีละครั้ง กดค้างไม่เลื่อนซ้ำอัตโนมัติ

## หน้าจอใหม่

- PIN: รหัสที่บันทึกแสดงเป็น `*` เลขที่กำลังเลือกแสดงตัวใหญ่ระหว่างลูกศร
- เมนู: TRANSPORT / DISPENSE / SERVICE ใช้กรอบและลูกศรแสดงรายการที่เลือก
- เลือกขวด / Transport / เปิดฝา: แสดง V1–V3 เป็นหลอดพลังพร้อมเปอร์เซ็นต์
- ขวดนำออก: แสดง OUT ในแถบ พร้อม Health ล่าสุดที่หยุดคำนวณแล้ว
- ขวดกักกัน: แสดง QUAR ในแถบว่าง พร้อม 0%
- หน้า Risk: แสดงอุณหภูมิ IN จริงและ SIM ภายนอก, Risk ตัวใหญ่ และแถบ Health ของขวดที่เลือก
- Service ใช้คำยืนยัน `2OVERRIDE` เพื่อไม่ซ่อนว่าผู้ดูแลกำลังยอมรับความเสี่ยง
- เปิดเกินเวลา: คงคำเตือน TIMEOUT และยังรอยืนยันปิดฝา ไม่สั่งล็อกเอง

Health แสดงเป็นจำนวนเต็มปัดใกล้สุด แต่ถ้ายังมากกว่า 0 จะแสดงอย่างน้อย 1%; สูตรและคะแนนภายในไม่เปลี่ยน พื้นที่แถบใช้ค่าเดียวกับตัวเลข จอเว้นขอบซ้าย/ขวา 4 พิกเซล

รายละเอียด ROLE, อุณหภูมิภายนอก, GAP และสถานะทั้งหมด ยังอ่านจากคำสั่ง STATUS ใน console ได้ หน้า Transport แสดง GAP หากประวัติอุณหภูมิไม่ครบ

## การตรวจสอบ

- CubeIDE headless Build ผ่าน 0 errors, 0 warnings
- ตรวจภาพจำลองสี่หน้าและขอบเขตข้อความ/แถบที่ 128x64 พิกเซล ภาพเป็นตัวอย่างเลย์เอาต์ ไม่ใช่ภาพถ่ายบอร์ด
- เปรียบเทียบ framebuffer ก่อนส่ง I2C เพื่อไม่ส่งภาพเดิมซ้ำ และบังคับวาดใหม่หลัง initialize/retry
- ยังไม่ได้ทดสอบปุ่มหรือจอจริงกับเฟิร์มแวร์ชุดนี้

หลังติดตั้ง กด F5 -> Clean/Build -> ลงบอร์ด แล้วปิดฝาด้วยมือและกด D2 เข้าหน้า PIN ใช้ D4/D5 เลือกเลขแทน Pot
