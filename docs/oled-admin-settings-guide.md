# Admin Settings บน OLED

ลงโปรแกรมใหม่ → รับทราบ TEMP ALARM ด้วย D3 ถ้ามี → HOME กด D2 → ใส่ Admin PIN (เริ่มต้น 2468) → เลื่อน D5 ไป ADMIN SETTINGS รายการที่ 4 หรือ D4 จาก TRANSPORT เพื่อวนไปท้าย → D2

เมนูมี OPEN TIME, NURSE PIN, ADMIN PIN

- OPEN TIME: D4 ลด / D5 เพิ่มครั้งละ 5 วินาที ช่วง 10–300 วินาที; D2 บันทึก; D3 ยกเลิก ค่าที่แก้ยังไม่ใช้จนกดบันทึก
- เปลี่ยน PIN: D4/D5 เลือกเลข D2 บันทึกทีละหลัก D3 ลบ กรอกใหม่ 4 หลักแล้วกรอกซ้ำให้ตรงกัน หากไม่ตรงหรือซ้ำรหัสอีกบทบาทจะไม่เปลี่ยน PIN
- D3 ขณะยังไม่มีเลข: ยกเลิกกลับ Settings
- สำเร็จแสดง SAVED (RAM ONLY) กด D2/D3 กลับ Settings
- พยาบาลไม่เห็นรายการ Settings และตัว state machine ตรวจสิทธิ์ก่อนแก้จริง
- เมนูหลักแสดงทีละ 3 รายการ เลื่อนถึงรายการที่ 4 แล้วหน้าจอเลื่อนตาม
- ค่าทั้งหมดอยู่ RAM รีเซ็ตเครื่องแล้วกลับเวลา 60 วินาที และ PIN 1234/2468
- เซนเซอร์และ Interrupt ยังทำงานระหว่างตั้งค่า การตั้งค่าที่ไม่บันทึกถูกยกเลิกเมื่อ session หมดเวลา

Build 0 errors / 0 warnings; ARM behavioral tests 18 checks ผ่าน ยังไม่ได้ Flash หรือทดสอบปุ่ม/OLED จริงบนบอร์ด
