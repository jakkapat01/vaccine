# เปิดอัตโนมัติและ LED เตือน

ผ่าน PIN และเลือกหลอด → ยืนยันหน้า Risk → ส่ง PWM เปิด Servo สำเร็จ → เข้าหน้า OPEN และเริ่ม Timer ทันที ไม่มีปุ่มยืนยัน OPENED อีก

ระบบถือว่าเปิดตามคำสั่ง Servo ไม่มี sensor ยืนยันการเคลื่อนที่จริง กรณี HAL ส่งคำสั่งไม่สำเร็จจะไม่เริ่มเวลาเปิด

เปิดเกินค่าที่ Admin ตั้ง: TIM2 ส่งเหตุหมดเวลา Main loop สั่ง LED PA5/PA6/PA7/PB6 (active high ตาม Exam2 BSP) ติดพร้อมกันแล้วสลับทุก 250 ms โดยไม่ใช้ delay จึงยังรับปุ่มและอ่านเซนเซอร์ได้ ไฟกระพริบต่อในหน้าปิดฝา/หน้าเตือนอุณหภูมิ จนยืนยันปิดฝา

D2 จบงาน → หน้าปิดฝา → D2 ยืนยันปิด/ส่งคำสั่ง Servo ปิดตามเดิม LED ดับและหยุด Timer ไม่ปิดเองเมื่อหมดเวลา

Build 0 errors / 0 warnings; ARM tests 19 checks ผ่าน (state 10, GPIO mock 9) ยังไม่ได้ Flash หรือยืนยันการเคลื่อนที่ Servo/ไฟจริงบนบอร์ด
